# Personal Resume Website

This repository contains the source code for a simple, static personal resume website. It is built using only HTML and is designed to be easily viewed in any modern web browser.

## Purpose

The primary purpose of this project is to provide a clean and straightforward online resume for Seo-yun. It serves as a digital portfolio, showcasing her skills, work experience, and educational background to potential employers and professional connections. The website is designed to be a static, single-page application, ensuring fast loading times and easy navigation.

## Usage

To view the resume, no special setup is required. Simply follow these steps:

1.  Clone or download this repository to your local machine.
2.  Navigate to the root directory of the project.
3.  Open the `index.html` file in your preferred web browser (e.g., Chrome, Firefox, Safari).

There are no dependencies or build steps required.

## Structure

The repository has a very simple structure:

-   `index.html`: This is the main and only HTML file. It contains the entire structure and content of the resume, including all sections from the summary to the footer. The file is heavily commented to explain the purpose of each HTML tag and section.
-   `README.md`: This file, which you are currently reading. It provides a comprehensive guide for anyone interacting with this repository.
